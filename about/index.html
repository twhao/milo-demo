Milo

Milo 主题的官方演示站，展示简洁、舒适的博客阅读体验。

这里是 Milo · 主题演示。Milo 是一款面向个人博客的 Hexo 主题。本站通过设计手记、技术笔记和城市随笔，展示文章排版、目录、图文阅读与归档。

文章中的生活场景和项目经历均为演示内容。排版校样为本站原创，雨窗静物、书桌与冬日窗影为生成素材。河岸实景照片由 David Dixon 拍摄，采用 CC BY-SA 2.0 授权，原作及处理说明见文章图注。

可以从我在手机上重排了一篇旧文开始，看段落、表格和插画如何放在同一篇文章里。一串文件名怎样撑宽了卡片保留了长代码与多级标题，那场雨没有照片的正文则以纯文字呈现。想随便翻翻，可以去归档，也可以订阅 Atom。

在自己的博客里使用 Milo

已有 Hexo 博客的话，可以从版本发布页挑选一个版本，按 README 的安装说明安装并启用 Milo。主题源码和更新记录都在 GitHub 仓库。
